# d20-dmhub

The Lua source code for the **D&D 5e (d20) game system** that runs inside the DMHub virtual
tabletop. Everything here runs as a set of Lua "code mods" loaded by the DMHub desktop app;
there is no standalone build or interpreter.

The engine itself (C#/Unity) is closed source. This repo is the game system that runs on top of
it: the 5e rules engine, character sheets, spells, the compendium editors, the in-game HUD, and
most of the UI.

## Repository layout

Each top-level directory is one DMHub code mod, named by its display name. The `require()`
namespace for each mod (used inside the Lua files and `main.lua`) is the sanitized name plus the
last 4 hex digits of its mod id:

| Directory | require() namespace |
|---|---|
| `DMHub Titlescreen/` | `DMHub_Titlescreen_6089` |
| `DMHub Core UI/` | `DMHub_Core_UI_752e` |
| `DMHub Core Panels/` | `DMHub_Core_Panels_65a9` |
| `DMHub Utils/` | `DMHub_Utils_5b73` |
| `DMHub CharacterSheet Base/` | `DMHub_CharacterSheet_Base_b03e` |
| `DMHub Game Rules/` | `DMHub_Game_Rules_fc51` |
| `DMHub CharacterSheet 5e/` | `DMHub_CharacterSheet_5e_b1b6` |
| `DMHub Game Hud/` | `DMHub_Game_Hud_efeb` |
| `DMHub Compendium/` | `DMHub_Compendium_c080` |
| `DMHub Token UI/` | `DMHub_Token_UI_203c` |
| `DMHub Import Framework/` | `DMHub_Import_Framework_6cc3` |
| `DMHub 5e System/` | `DMHub_5e_System_7c33` |
| `5eTools Importer/` | `5eTools_Importer_14f9` |

Other items:

- `main.lua` - the module load-order index, for editor/LSP tooling. The engine's runtime load
  order comes from each mod's cloud file list; this mirrors it.
- `Definitions/` - LuaLS type stubs for the engine's Lua API (`dmhub`, `gui`, `game`, ...).
  Generated by the engine; an editor running the Lua language server gets completions and type
  checking against the engine surface.

## How this content is loaded

**Retail (stable 0.5x builds):** the app syncs these mods from the cloud. Local editing uses the
in-app checkout flow (Compendium -> Code Mods -> Check Out Code), which writes a mod's files to
the app's data folder (`%USERPROFILE%\AppData\LocalLow\Sodapods\DMHub\mods\`).

**Dev builds (0.7x+, engine with git-folder support):** point the app's modding config at a
clone of this repo and it loads every matching module's `.lua` directly from your working copy,
watching for changes:

1. Enable Developer Mode (`/dev true` in chat).
2. Open the modding config: `%USERPROFILE%\AppData\LocalLow\<Company>\<Product>\mods\settings.json`.
3. Set `"gitfolder"` to your clone path (forward slashes), restart the app.
4. Each top-level directory here matches a module by name; matching modules load from your clone
   and hot-reload on save (F4 if auto-reload is off).

Note: only one game system can own `gitfolder` at a time -- if you also develop the Draw Steel
Codex from a git clone, switch the setting (and restart) when switching systems.

## Provenance

The baseline content in this repo is the 5e mod set as shipped at engine 0.526 (the last stable
5e-era release), materialized from the cloud. Modernization work targeting newer engines
(0.75x+) is layered on top in subsequent commits -- see the commit history and the migration
research report in the engine repo for the full analysis.

## Lua constraints

- **ASCII only** - the DMHub Lua runtime does not handle non-ASCII characters in source files.
- **Do not create new Lua files on disk** - modules and files are registered through DMHub's mod
  system; a file dropped into a module folder will not auto-load. Create files through the
  in-app Code Mods editor first.
